محطة 6 • فحص الجودة الإلزامي The Supreme Judge

بوابة التحقق النهائي المستقل (Independent Validator)

حتى لو ادعت أي خوارزمية داخلياً أنها وجدت حلاً (SOLVED)، فإن Algorithm Runner يمرر الحل بصورة مستقلة على دالة validate_solution. لو وجد أي تقاطع أو شبكة مقطوعة، يتم رفض الحل فوراً وتعديل الحالة إلى NO_VALID_SOLUTION_FOUND لحماية واجهة المستخدم من أي تضليل.

🧪 إزاي تتأكد بنسبة 100% إنه صح؟ (طريقة الفحص)

1. شغل الاختبار الشامل:

pytest tests/test_backtracking_solver.py -v

2. اختبار P1 الأساسي: لازم يرجع بالضبط [1, 1, 1, 1] مع status="SOLVED".

3. اختبار No Solution: اعطه لغز مستحيل، اتأكد إنه استكشف ورجع "UNSATISFIABLE" مش Null أو Exception.

4. اختبار Limit Reached: اعطه max_states=5 وشوف هل بيرجع "LIMIT_REACHED" بأمان.

⛔ Red Flag (ارفض الـ PR لو لقيت ده): لو خلط بين القيمة 0 (قرار عدم وضع جسر) والقيمة None (حالة غير محسومة)، أو لو كان الـ undo بيسرب حالة ومش بيرجع درجات الجزر لأصلها بالضبط.

🧪 إزاي تتأكد بنسبة 100% إنها صح؟ (طريقة الفحص)

1. شغل اختبارات الـ GA:

pytest tests/test_ga_solver.py -v

2. Round-trip lossless test: تأكد أن تحويل chromosome -> solution -> chromosome لا يفقد أي قيمة.

3. اختبار اللياقة على P1: الكروموسوم [1,1,1,1] يجب أن يرجع بالضبط (0, 0, 0).

4. فحص الـ Seed: تأكد إنه مع تثبيت الـ seed، النتيجة تتكرر بنسبة 100%.

⛔ Red Flag (ارفض الـ PR لو لقيت ده): لو رجعت الحالة "UNSATISFIABLE" لما تخلص عدد الـ generations (يجب أن ترجع NO_VALID_SOLUTION_FOUND فقط لأنها احتمالية)، أو لو أعادت ترتيب الجسور في الكروموسوم.
