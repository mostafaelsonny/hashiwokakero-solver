# مصادر التعلم (موجّهة، مش كورسات كاملة)

الهدف إنك تفهم الفكرة وتقدر **تراجع** تنفيذ الـ AI، مش إنك تتحول لمتخصص في أسبوع. اتعلم الجزء المتعلق بمهمتك بس.

| الموضوع | المصدر المقترح | لمين |
|---|---|---|
| قواعد Hashiwokakero | صفحة اللعبة على موقع Nikoli | الكل (≈ ساعتين) |
| BFS وDFS | موقع VisuAlgo (محاكاة بصرية) | الكل، وEbrahim وMonzer بعمق |
| Recursion / Backtracking (مقدمة) | CS50 — Introduction to Algorithms (مراجعة مفاهيم فقط، مش الكورس كله) | Ebrahim + الكل |
| CSP / Pruning / Variable Ordering | UC Berkeley — Introduction to AI: Solving Constraint Satisfaction Problems | Ebrahim (اختياري للباقي) |
| Genetic Algorithms | Introduction to Genetic Algorithms — Algorithm Afternoon | Rovan + الكل (مقدمة) |
| Memetic Algorithms | A Primer on Memetic Algorithms (University of Surrey) — فكرة Local Search مع Evolutionary فقط | Febronia + Rovan |
| React + TypeScript | التوثيق الرسمي لـ React (TypeScript) + Vite | Febronia + Mostafa |
| Pytest | التوثيق الرسمي لـ Pytest | الكل |

## مفاهيم لكل عضو
- **Monzer:** Graph Representation، Node Degree، Connected Components، BFS/DFS، Line Intersection، Constraint Validation.
- **Ebrahim:** Recursion، Search Tree، Backtracking، Constraint Checking، Pruning، Partial vs Final Validation.
- **Rovan:** Population، Chromosome، Fitness، Selection، Crossover، Mutation، Elitism.
- **Febronia:** Local Search، Neighborhood، Hill Climbing، Fitness Improvement، GA + Local Search، SVG.
- **Mostafa:** Modular Architecture، API Contracts، Integration، Testing Strategy، Code Review، Git Workflow.

## مستبعد (مش هنضيع وقت فيه)
Advanced Graph Theory • Advanced GA • Neural Networks • Deep Learning • Database Design • Authentication • Advanced React • Advanced Animation • Cloud Deployment.
