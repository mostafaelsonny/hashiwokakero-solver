# Project Requirements

**المادة:** AI310 / CS361 Artificial Intelligence — Fall 2026 (مشروع رقم 10)  •  **الفريق:** 5  •  **المدة:** 4 أسابيع

## المشكلة
Hashiwokakero: شبكة فيها جزر، على كل جزيرة رقم. المطلوب نوصّل الجزر بجسور بحيث كل القواعد تتحقق.

## القواعد (المرجع الرسمي للفريق)
1. **Degree:** مجموع الجسور على الجزيرة = رقمها بالظبط في الحل النهائي. الجسر المزدوج بيتحسب 2 على كل جزيرة من الاتنين. الرقم مش عدد الجزر المتصلة، هو عدد الجسور.
2. **أقصى جسرين** بين أي جزيرتين (0 أو 1 أو 2).
3. **ممنوع تقاطع** جسرين.
4. **Connectivity:** كل الجزر شبكة واحدة متصلة (مباشرة أو غير مباشرة). مجموعتين منفصلتين = حل غلط حتى لو الأرقام صح.
5. **أفقي أو رأسي بس**، ومفيش قطري.
6. **أقرب جزيرة مرئية:** الجسر بيوصل بين أقرب جزيرتين في نفس الصف/العمود من غير جزيرة بينهم. (قاعدة قياسية في اللعبة ومش مكتوبة صراحةً في ملف المشروع، فبنضيفها للمواصفات.)

شرط ضروري (مش كافي): مجموع أرقام الجزر لازم يكون **زوجي**، لأن كل جسر بيتحسب مرتين. لو فردي، اللغز مستحيل.

## المطلوب رسميًا من المشروع
| # | المتطلب | الأولوية |
|---|---|---|
| 1 | **Backtracking** يلاقي حل صحيح | Must |
| 2 | **Genetic Algorithm**: Population, Chromosome, Fitness, Selection, Crossover, Mutation | Must |
| 3 | **Memetic Algorithm** = GA + Local Search حقيقية (مش تغيير اسم) | Must |
| 4 | **Graph Theory**: اكتشاف التقاطعات + المجموعات المنفصلة | Must |
| 5 | **Puzzle Input**: أبعاد الشبكة + الجزر + أرقامها | Must |
| 6 | **اختيار الخوارزمية** | Must |
| 7 | **Visualization**: الجزر والجسور والنتيجة | Must |
| 8 | Live Animation | Optional |
| 9 | إحصائيات أداء متقدمة | Optional |
| 10 | تحسينات متقدمة للخوارزميات | Optional |

## المدخلات والمخرجات
- **المدخل:** Puzzle = `{rows, cols, islands: [{id, row, col, required_bridges}]}` + اسم الخوارزمية + إعدادات (GA/MA).
- **المخرج:** حالة (Status) + Solution = `{bridge_counts: {"E1": 0|1|2, ...}}` + إحصائيات + تقرير تحقق.

## الحالات اللي الواجهة لازم تفرّق بينها
| الحالة | معناها |
|---|---|
| Solution Found | حل عدّى على `validate_solution` |
| No Solution Exists | **Backtracking بس**، بعد بحث كامل وصحيح |
| Search Limit Reached | وقف بسبب حد الوقت/الحالات |
| No Valid Solution Found Within Search Limits | GA أو MA خلصوا من غير حل. **ممنوع** نقول "مستحيلة"، الخوارزمية احتمالية |
| Invalid Input | مدخلات غلط (جزيرتين في نفس الخلية، خارج الشبكة، رقم غير مسموح) |

## Minimum Viable Project (متى نعتبر المشروع مكتمل)
- المستخدم يدخل الجزر وأرقامها ويختار الخوارزمية ويشوف الشبكة والحل.
- Backtracking بيلاقي حلول صحيحة للأمثلة المدعومة.
- GA فيها Population وFitness وSelection وCrossover وMutation.
- MA بتستخدم GA وتضيف Local Search فعلية.
- النظام بيكتشف التقاطعات والشبكات المنفصلة.
- **الحل النهائي مبيتقبلش إلا بعد `validate_solution`** (Validator مشترك للـ 3 خوارزميات).
- فيه Test Cases تثبت عمل الأجزاء الأساسية.
