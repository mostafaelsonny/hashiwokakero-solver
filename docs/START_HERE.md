## 1) المشروع في جملة
برنامج بيحل لعبة منطقية اسمها **Hashiwokakero** (أو Bridges) بتلات طرق مختلفة من الذكاء الاصطناعي، وبواجهة بتدخّل فيها اللغز وتختار الطريقة وتشوف الحل.
ده مشروع مادة **AI310 / CS361 Artificial Intelligence** (Fall 2026)، مدته **4 أسابيع**، والمطلوب منا نثبت 3 حاجات للدكتور:
1. فاهمين المشكلة وقواعدها.
2. نفذنا الخوارزميات التلاتة صح وبشكل مفهوم.
3. عندنا برنامج بيستقبل لغز ويشغّل الخوارزمية المختارة ويعرض النتيجة.

## 2) اللعبة
عندك شبكة فيها **جزر**، كل جزيرة عليها **رقم**. لازم توصّل الجزر بـ **جسور** بالقواعد دي (كلها مع بعض):

1. **الرقم = عدد الجسور المتصلة بالجزيرة بالظبط.** مش عدد الجزر المتصلة بيها. الجسر المزدوج بيتحسب 2.
2. الجسور **أفقية أو رأسية** بس (مفيش قطري).
3. الجسر بيوصل بين **أقرب جزيرتين** في نفس الصف أو العمود، **من غير جزيرة بينهم**.
4. أقصى عدد بين أي جزيرتين = **جسرين**.
5. **ممنوع جسرين يتقاطعوا.**
6. كل الجزر لازم تبقى **شبكة واحدة متصلة** (مباشرة أو غير مباشرة).

### مثال صح (Puzzle P1، شبكة 3×3)
```
A(2) ──── B(2)
 │         │
C(2) ──── D(2)
```
كل جزيرة عليها جسرين (واحد أفقي وواحد رأسي) = رقمها 2 ✔، مفيش تقاطع ✔، الشبكة كلها واحدة ✔.

### أمثلة غلط (لازم تعرف تفرّق)
| الحالة | ليه غلط |
|---|---|
| جزيرة رقمها 3 ومتوصلة بجسرين بس | الـ Degree ناقص |
| جزيرة رقمها 2 ومتوصلة بـ 3 جسور | الـ Degree زايد |
| 3 جسور بين جزيرتين | الحد الأقصى 2 |
| جسر أفقي بيقطع جسر رأسي | تقاطع |
| جسر بيعدي فوق جزيرة تالتة | لازم يوصل لأقرب جزيرة |
| A–B و C–D لوحدهم من غير اتصال بينهم (الأرقام سليمة) | شبكتين منفصلتين |

> في P1 فيه ملاحظة مهمة: الحلين `A–B مزدوج + C–D مزدوج` و`A–C مزدوج + B–D مزدوج` بيحققوا الأرقام كلها، لكن **الشبكة مقسومة لمجموعتين**، فهم **غلط**. الحل الصحيح الوحيد هو الجسور المفردة الأربعة.

## 3) المشكلة اللي بنحلها (من منظور علوم الحاسب)
- كل **جسر محتمل** بين جزيرتين = **متغير** قيمته 0 أو 1 أو 2 (مفيش جسر / جسر / جسرين).
- القواعد = **قيود** (Constraints): Degree، التقاطع، الاتصال. ده اسمه **Constraint Satisfaction Problem (CSP)**.
- لو عندنا 20 جسر محتمل، عدد التوزيعات الممكنة 3²⁰ ≈ **3.5 مليار**. يعني مينفعش نجرب كل حاجة من غير ذكاء، وده سبب وجود 3 خوارزميات.

## 4) الخوارزميات التلاتة (الفكرة بس)
| الخوارزمية | الفكرة | بتضمن إنها تلاقي حل؟ |
|---|---|---|
| **Backtracking** | نجرب قيمة لكل جسر بالترتيب، ولو الاختيار مستحيل يوصّل لحل (Pruning) نرجع ونغيّره | **أيوه**، لو البحث كامل وصحيح، وتقدر تثبت إن مفيش حل |
| **Genetic Algorithm (GA)** | نبدأ بمجموعة حلول عشوائية (Population)، نقيّم كل حل (Fitness)، نختار الأحسن (Selection)، نخلّف حلول جديدة (Crossover) ونغيّر فيها شوية (Mutation)، ونكرر على أجيال | **لأ**، احتمالية وممكن تفشل |
| **Memetic Algorithm (MA)** | GA + **Local Search**: كل حل بنحسّنه بتعديلات صغيرة مدروسة قبل الجيل الجاي | **لأ**، لكن غالبًا أحسن من GA |

لو GA أو MA خلصوا من غير حل، **ممنوع** نقول "اللغز مستحيل"، بنقول: `No Valid Solution Found Within Search Limits`.

## 5) Graph Theory (ليه محتاجينها)
- الجزيرة = **Vertex**، الجسر = **Edge**.
- **Degree** = عدد الجسور على الجزيرة.
- **Connected Components** = المجموعات المنفصلة. بنكتشفها بـ **BFS أو DFS**. لو العدد = 1 الشبكة متصلة.
- **اكتشاف التقاطع** بالإحداثيات: جسر أفقي في الصف r بين العمودين c1 < c2، وجسر رأسي في العمود c بين الصفين r1 < r2، بيتقاطعوا لو وبس لو `c1 < c < c2` و`r1 < r < r2` (مقارنة صارمة).

## 6) النظام متقسم ازاي
```
Frontend (React)  →  API (FastAPI)  →  Backtracking / GA / MA
                                            ↓ (كلهم بيستخدموا)
                          Core Engine: candidate edges, degree, crossings, connectivity, validator
```
- **Core Engine** (`core/`) فيه القواعد في مكان واحد. الخوارزميات التلاتة بتنادي عليه ومبتكتبش قواعد خاصة بيها.
- **`validate_solution`** هو **الحَكَم الوحيد**: ممنوع أي خوارزمية تقول "Solution Found" قبل ما يوافق.
- **Data Model** واحد ([DATA_MODEL.md](DATA_MODEL.md)): كلنا بنتعامل بنفس الشكل بالحرف.

## 8) كلمات لازم تعرفها
| الكلمة | معناها |
|---|---|
| Island | جزيرة: `{id, row, col, required_bridges}` |
| Candidate Bridge | جسر **محتمل** بين أقرب جزيرتين (من غير ما نحدد عدده) |
| bridge_counts | عدد الجسور الفعلي لكل Candidate Bridge (0/1/2): ده الـ Solution |
| Degree | مجموع الجسور على الجزيرة |
| Partial vs Final Validation | Partial: الجزيرة ماتعدّيش رقمها (أثناء البحث). Final: تساوي رقمها بالظبط |
| Pruning | نرجع فورًا من مسار مستحيل بدل ما نكمله |
| Chromosome / Gene | الحل كـ Array من 0/1/2، وكل خانة = جسر محتمل |
| Fitness / Penalty | درجة جودة الحل (كل ما الـ Penalty قل كل ما كان أحسن) |
| Local Search | تحسين حل موجود بتعديلات صغيرة حواليه |
| PR (Pull Request) | طلب دمج شغلك في `develop` بعد مراجعة Mostafa |
